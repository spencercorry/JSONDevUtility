How to Use

  1. Paste or type JSON into the left editor pane.
  2. Beautify formats the JSON. Use the 2 / 4 indent toggle to control spacing — switching reruns Beautify automatically.
  3. Submit opens the configuration modal. Set a root type name, configure any null fields (required before generating), and expand Advanced Options to override types or mark fields optional.
  4. Generate produces typed output. Switch between the TypeScript, Pydantic, and JS Object tabs on the right to see each format.
  5. Copy copies the current tab's output to the clipboard.
  6. Clear (visible after the first Submit) empties the editor and resets all output.
  7. Reopening Submit restores your previous root type name, field types, and optional flags so you only need to change what differs.
Tip Null fields in your JSON must have at least one type selected before Generate is enabled. Use the opt button on any field to mark it optional in the output.
Beta TypeCast is currently in beta. You may encounter bugs or incomplete features — feedback is appreciated.
